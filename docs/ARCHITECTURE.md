# 程序结构

`scope.py` 用列表标题及同条摘要做代码筛选，先排除会议、人事、发言等非政策，再判断能源主题与政策文件特征。主题不明确不获取正文，不借导航或机构名称推断能源主题，也不调用 AI。

`collect.py`、`parse.py`、`dynamic.py` 和 `navigation.py` 处理栏目发现、翻页、动态接口与详情；浏览器作为回退。附件支持 PDF、Office 文档、压缩包及图片 OCR。正文、必要附件及证据通过完整性验收才能成为成功记录；网络可达、栏目列表和网页字符数均不能代替验收。分页不完整或站点不可达需在来源状态中说明。

`cli.py` 分 collect、finalize、receipt 三阶段。可靠日期仅取最近七天，未知日期另存；`analysis.py` 验证宿主分析不得更改代码事实。`taxonomy.py` 使用本地机构、行业和标签字典；`mi_checks.py` 验证本地资产、参考表及生成 Excel。`export.py` 写真实超链接。`host_delivery.py` 验证附件摘要与实际发送回执，只在成功发送后推进去重。

`paths.py` 和 `runtime.py` 将所有写入、配置、临时文件、依赖及浏览器缓存限制在包目录。`bootstrap.py` 创建本地环境；`run_weekly.py` 只运行该环境。现有基础 Python 是前提，不自行全局安装。公开目录没有业务数据，须本地导入后才有真实来源和分类基准。

宿主提供 AI、定时与邮件连接。本包保留通用与动态站点适配代码，但不含已核验站点清单或覆盖报告；真实入口、分页、签署者、核心附件和正文成功率必须本地逐站验收。单元测试通过不代表某站实时可用，也不表示在每种宿主完成实际邮件与调度测试。
