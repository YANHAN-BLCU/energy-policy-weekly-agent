# 迁移

克隆公开仓库到工作目录，保留根目录与嵌套入口 SKILL.md。使用已有 Python 运行 bootstrap.py --browser，在新目录重建 .venv 和 .runtime，不搬旧环境、不全局安装技能或依赖。先用虚构示例和 scripts/run_tests.py 验证代码；实际使用应另设生产工作目录，导入本地私有来源与字典，不混用演示数据。

只读导入私有 JSON 后生成本地独立字典文档与校验清单；所有业务资产必须留在被忽略的路径。检查时核对与用户参考表是否一致，包括机构英译、办公厅层级、联合发文、分类配对及嵌入图片。原表未提供只能检查本地资产一致性，不宣称原表验收完成。

收集或复用邮箱、星期和触发时间，在新宿主连接自身附件邮件与原生调度能力，并更新为新包的绝对路径。只在工具返回真实成功回执后报告定时与邮件可用。迁移去重状态和待发送运行时应本地复制到 runs；证据路径随目录变化需核对，不能把已发送附件改写后沿用旧摘要。

公开推送前运行 scripts/check_public_tree.py 并人工审查 Git 跟踪文件。禁止推送真实配置、字典、表格、采集正文、报告、邮箱、回执、日志、运行环境和私有打包文件。公开代码版本不等于含数据的私有交付包。
